* Perdido

It means "missing" in Portuguese. Here to provide the "missing" api for what is supported in rancher.

I made AI build most of it, parsing html is not my favorite thing and the result is good enough to start using in other things which is the real use case.

** Building

Its a cargo package you should be able to run it "normally", but dependency management is a you thing. Otherwise the nix flake provides all the batteries needed.

Run the test suite which is mostly html fragment parsing to prove out functions really.

#+begin_src sh
nix flake check
#+end_src


Build the static linux binary to run elsewhere I guess, not sure why you'd want to.

#+begin_src sh
$ find $(nix build .#perdido-portable --print-out-paths --no-link) -iname perdido
/nix/store/qvlngdb9i13nbm85kmx88mrnqmigg2fn-perdido-x86_64-unknown-linux-musl-0.1.0/bin/perdido
#+end_src

Windows:

#+begin_src sh
$ find $(nix build .#perdido-windows --print-out-paths --no-link) -iname perdido.exe
/nix/store/q9yv6kfnpb9cfpp8ia5ks7dpzin5899j-perdido-x86_64-w64-mingw32-0.1.0/bin/perdido.exe

Macos you'll need to build/run on a nix equipped mac. But its basically the same as the linux example.
